# Sessions snapshot their Questions instead of referencing the Set live

A Survey Set or Question Set can be reused across many Sessions over time, and lecturers need to keep editing Sets between lectures (fixing typos, tweaking answers). If a Session referenced its Set live, editing a Set after a Session ran would silently rewrite that Session's historical results — e.g. changing a Question's correct answer would retroactively change past students' scores and the recorded analysis. We decided a Session copies its Questions (and, for a Question Set, their correct answers) at the moment it starts, decoupling it from later edits to the source Set. The lecturer can freely edit a Set for future Sessions; past Sessions' results stay exactly as recorded. Retrofitting this after results exist without it would be painful, so it's decided up front.
