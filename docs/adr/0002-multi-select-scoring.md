# Multi-select Quiz Session scoring: partial credit per option, floored at zero

Adding a multi-select Question (ticket #10) raised a scoring question that single-select never had to answer: a Student can now get a Question partially right, so all-or-nothing scoring no longer fits. We considered full credit only for an exact match of the selected set against the correct set, but that throws away the difference between a Student who is one option off and one who guesses randomly, which feels punitive for a "choose all that apply" prompt. We decided each Question scores independently as (number of correctly selected options) minus (number of incorrectly selected options), floored at zero so a bad guess can't push a Question's contribution below what leaving it unanswered would have scored; the Session's total is the sum across Questions, unchanged from today. This reduces to the original 1-point-correct/0-point-wrong rule for a single-select Question, so no existing Leaderboard behavior changes. Retrofitting a different formula after Students have seen scores under this one would be confusing, so it's decided up front (see `getLeaderboard` in `src/lib/leaderboard/leaderboard-service.ts`).
